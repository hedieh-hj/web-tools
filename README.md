# Gemini Custom Persian Font (Stylus / UserCSS)

یک استایل سفارشی برای بهبود خوانایی و تایپوگرافی متن‌های فارسی و انگلیسی در نسخه وب **Google Gemini** با استفاده از افزونه‌های مدیریت استایل کاربر مانند **Stylus**.

A lightweight custom user style designed to enhance Persian/Arabic typography on **Google Gemini** using modern web fonts while preserving code blocks and system icons.
